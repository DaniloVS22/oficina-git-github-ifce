# CyberQuiz IFCE — Oficina de Git e GitHub

Quiz interativo com **10 perguntas** sobre segurança digital, explicações e perguntas para debate.

## Como executar
1. Abra a pasta no VS Code.
2. Abra `index.html` no navegador (ou use a extensão Live Server).
3. Clique em **Começar desafio**.

## Arquivos
- `index.html`: estrutura da página
- `style.css`: visual
- `script.js`: perguntas e funcionamento

## Sugestão para a oficina Git
Use `git init`, `git add .`, `git commit -m "Cria CyberQuiz IFCE"` e registre um novo commit depois que os alunos personalizarem uma pergunta ou uma cor. Nunca coloque senhas reais no projeto.
